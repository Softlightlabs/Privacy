# Softlight Labs Privacy

Public privacy-policy repository for Softlight Labs apps.

## Ritual

Source policy: `ritual/index.html`

The Ritual page is prepared from the current policy in `Softlightlabs/Ritual`, but **must not be published as the final Play privacy-policy URL until an approved public support/privacy contact has been inserted**.

Planned public URL after GitHub Pages is enabled:

`https://softlightlabs.github.io/Privacy/ritual/`

## Publishing

1. Insert the approved public contact in `ritual/index.html`.
2. Enable GitHub Pages for this repository from the `main` branch / root.
3. Verify the page opens without authentication over HTTPS.
4. Use the resulting Ritual URL in Google Play Console → App content → Privacy policy.
